# TennisAbstract 2025 ATP Match Scraper

Production-ready ETL tool to scrape ATP 2025 completed matches from TennisAbstract and output them in Jeff Sackmann's `tennis_atp` CSV format.

## Features

- ✅ Scrapes ATP 2025 matches from TennisAbstract
- ✅ Automatic tournament discovery
- ✅ Robust error handling and retries
- ✅ Player ID mapping using Sackmann's database
- ✅ Manual name override support
- ✅ Rate limiting and respectful scraping
- ✅ JSONL for raw data, CSV for processed output
- ✅ Fully compatible with existing `tennis_atp` data

## Setup

### Installation

```bash
cd tennisabstract_2025
pip install -e .
```

Or install dependencies directly:

```bash
pip install requests beautifulsoup4 pandas unidecode tqdm python-dateutil lxml
```

### Required Files

1. **Player Database**: Place `atp_players.csv` in `data/sackmann/`
   - Download from: https://github.com/JeffSackmann/tennis_atp
   - Should contain columns: `player_id`, `name`, etc.

2. **Name Overrides** (optional): Create `mappings/name_overrides.csv`
   - Format: `original_name,player_id`
   - Use this for players that don't match automatically

## Usage

### Complete Pipeline

Run the full pipeline (discover → scrape → normalize → CSV):

```bash
python -m ta2025 run --year 2025
```

For 2026 tournaments:

```bash
python -m ta2025 run --year 2026
```

### Test with Sample URL

Test the scraper with the provided sample URL:

```bash
python test_scraper.py
```

This will test scraping: `https://www.tennisabstract.com/current/2026ATPHongKong.html`

### Individual Steps

**1. Scrape tournaments only:**

```bash
python -m ta2025 scrape --year 2025
```

This will:
- Discover all ATP 2025 tournament pages
- Scrape completed matches
- Save to `data/raw/tennisabstract_2025_matches.jsonl`

**2. Build CSV from scraped data:**

```bash
python -m ta2025 build-csv --year 2025
```

This will:
- Load raw JSONL data
- Map player names to IDs
- Normalize to Sackmann format
- Write `data/processed/atp_matches_2025.csv`
- Report missing player IDs to `data/raw/missing_player_ids.csv`

## Configuration

### Adding Name Overrides

If a player name doesn't match automatically, add it to `mappings/name_overrides.csv`:

```csv
original_name,player_id
"John Smith",123456
```

### Custom Directories

```bash
python -m ta2025 run --year 2025 \
    --data-dir custom_data \
    --mappings-dir custom_mappings \
    --output-dir custom_data/raw
```

## Output Files

### Raw Data
- `data/raw/tennisabstract_2025_matches.jsonl` - Raw scraped matches (one JSON per line)
- `data/raw/missing_player_ids.csv` - Players that couldn't be matched to IDs

### Processed Data
- `data/processed/atp_matches_2025.csv` - Final output in Sackmann format

## How It Works

1. **Discovery**: Finds all ATP 2025 tournament pages on TennisAbstract
2. **Scraping**: Extracts completed matches from each tournament page
3. **Storage**: Saves raw data as JSONL for debugging/reprocessing
4. **Normalization**: Converts to Sackmann-compatible format
5. **ID Mapping**: Matches player names to IDs using multiple strategies
6. **CSV Output**: Writes final CSV with exact column order

## Error Handling

- Failed requests are retried up to 3 times
- Rate limiting: 0.5-1.0 seconds between requests
- Tournament parsing failures are logged but don't stop the pipeline
- Missing player IDs are tracked and reported

## Logging

The tool provides detailed logging:
- Progress bars for long operations
- Tournament URLs and match counts
- Parsing failures with reasons
- Missing player ID summaries

## Re-running Safely

The scraper is designed to be re-runnable:
- Raw JSONL can be regenerated by re-scraping
- CSV can be rebuilt from existing JSONL
- Player mappings are cached in memory

## Troubleshooting

### No tournaments discovered
- Check TennisAbstract website structure hasn't changed
- Add fallback tournament URLs to `discover.py`

### Missing player IDs
- Check `data/raw/missing_player_ids.csv`
- Add entries to `mappings/name_overrides.csv`
- Verify `data/sackmann/atp_players.csv` is up to date

### Parsing failures
- Check logs for specific tournament URLs
- TennisAbstract page structure may have changed
- Update selectors in `scrape_tournament.py` if needed

## Important Notes

- **DO NOT** hardcode column names - they come from the provided column list
- **DO NOT** merge with historical data - outputs 2025 only
- **DO NOT** infer missing data - leave fields blank ("")
